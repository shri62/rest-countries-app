# Project Reflection: REST Countries API with Color Theme Switcher

## Development Process

I developed a REST Countries application using HTML, CSS, and JavaScript. My goal was to build a responsive website that allows users to explore country information. I organized the project into three main files: `index.html` for the page structure, `style.css` for styling, and `script.js` for functionality. I used the REST Countries API to retrieve country data and display it dynamically.

## Challenges and Solutions

One challenge was connecting the application to the API and handling the returned country data. I researched the API configuration, checked the browser console, and corrected the data handling so country information could display properly.

I also implemented search functionality, region filtering, country detail views, border-country navigation, and a light and dark theme switcher. Testing helped me identify an accessibility issue with country flag images. I fixed it by adding descriptive `alt` text to the images. I also tested keyboard navigation and checked the layout on mobile and desktop screen sizes.

Another important part of the process was using Git and GitHub to track my changes and publish my source code.

## Potential Improvements

In the future, I would improve error handling and loading indicators, refine the visual design, and perform more thorough accessibility and color-contrast testing. I would also review API key security before making the application publicly available.

## What I Learned

This project helped me practice working with APIs, JavaScript DOM manipulation, event handling, responsive CSS, accessibility, and Git workflows. It also taught me the importance of testing features and researching unfamiliar technologies independently.
